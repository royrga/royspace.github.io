## Descripción

Este post contiene los resultados obtenidos durante el proceso de aprendizaje/experimentación
de el entorno Processing. También se incluyen animaciones realizadas con Shaders.

### Conceptos

**Programación creativa(Creative Coding):** es la práctica de usar el código
informático como un medio para crear obras artísticas, experiencias
interactivas y diseños visuales expresivos, más que funcionales. Se enfoca en
la expresión personal, la experimentación y la exploración, combinando el
arte con la tecnología para generar arte visual, instalaciones interactivas,
arte sonoro, visuales en vivo y más.

**Processing:** El software Processing es un entorno de programación de código
abierto diseñado para artistas, diseñadores y principiantes que buscan crear
gráficos, animaciones y visualizaciones interactivas de manera sencilla.

**Shaders:** Un shader es un programa especializado que se ejecuta en la unidad
de procesamiento gráfico (GPU) para determinar cómo se renderizan y se ven los
elementos en una pantalla. Estos programas utilizan cálculos matemáticos para
procesar datos de iluminación, texturas y otros parámetros, y así calcular el
color final de cada píxel.
