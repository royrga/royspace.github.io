## Description

This post contains the results obtained during the learning/experimentation process
with the Processing environment. Animations created with Shaders are also included.

### Concepts

**Creative Coding:** is the practice of using computer code as a means to create artistic works, interactive experiences, and expressive, rather than functional, visual designs. It focuses on personal expression, experimentation, and exploration, combining art with technology to generate visual art, interactive installations, sound art, live visuals, and more.

**Processing:** The Processing software is an open-source programming environment designed for artists, designers, and beginners looking to easily create interactive graphics, animations, and visualizations.

**Shaders:** A shader is a specialized program that runs on the graphics processing unit (GPU) to determine how elements are rendered and displayed on a screen. These programs use mathematical calculations to process lighting data, textures, and other parameters, and thus calculate the final color of each pixel.
